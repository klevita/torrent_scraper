# Torrents scraper

## 🚀 Описание проекта

Скрапер на Node.js с использованием Puppeteer для парсинга данных со страницы "Горячее". Проект включает тесты на Vitest.

## 📦 Установка

1. Клонируйте репозиторий:
   ```bash
   git clone <repository-url>
   cd <project-folder>
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

## ⚙️ Настройка

Создайте файл `.env` в корне проекта и укажите необходимые переменные окружения:
```
BACKEND_API_URL=http://your-backend-api.com
SCRAPER_TIMEOUT=30000
HEADLESS_MODE=true
```

## 🏃 Запуск

### Основной скрипт
```bash
npm start
```
или
```bash
node src/index.js
```

### Запуск в режиме разработки (с отключенным headless)
```bash
npm run dev
```

### Запуск тестов
```bash
npm test
```

### Запуск тестов с покрытием
```bash
npm run test:coverage
```

## 📝 Функциональность

Скрапер выполняет следующие действия:
1. Открывает страницу "Горячее"
2. Парсит строки таблицы
3. Извлекает необходимые данные
4. Отправляет данные на бэкенд для сохранения

## � Тестирование

Проект использует Vitest для unit-тестирования. Тесты расположены в директории `__tests__`.

Основные тесты:
- Парсинг таблицы
- Валидация данных
- Интеграция с API бэкенда

## ⚠️ Известные проблемы

1. При медленном интернете могут потребоваться дополнительные таймауты
2. Изменения в структуре страницы могут сломать парсинг
