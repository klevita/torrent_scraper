# Torrents scraper

## 🚀 Описание проекта

Скрапер на Node.js с использованием Puppeteer для парсинга данных со страницы "Горячее". Проект включает тесты на Vitest.

## 📦 Установка

1. Клонируйте репозиторий:
   ```bash
   git clone <repository-url>
   cd <project-folder>
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

## 🏃 Запуск

### Основной скрипт
```bash
npm run scrap
```
или
```bash
node main.js
```

### Запуск тестов
```bash
npm run test
```

## 📝 Функциональность

Скрапер выполняет следующие действия:
1. Открывает страницу "Горячее"
2. Парсит строки таблицы
3. Извлекает необходимые данные
4. Отправляет данные на бэкенд для сохранения

## � Тестирование

Проект использует Vitest для unit-тестирования. Тесты расположены в директории `tests`.

Основные тесты:
- Парсинг таблицы
- Валидация данных
- Интеграция с API бэкенда
